# ArrayLab Exercises

1. Change linear search to return every index where the target appears.
2. Explain why binary search requires sorted input.
3. Count comparisons in insertion sort and compare best-case and worst-case inputs.
4. Modify the merge routine to remove duplicates while merging.
5. Change duplicate compaction to report how many values were removed.
6. Extend two-sum to report all distinct index pairs, not only the first.
7. Multiply a 2×3 matrix by a 3×2 matrix and document the dimension rule.
8. Add boundary tests for empty arrays and arrays with one value.

Compile with warnings enabled and keep array lengths explicit. Do not read beyond fixed-size arrays.
